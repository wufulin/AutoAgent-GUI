# 创建定时任务

定时任务固定一个技能版本及参数，按 Cron 在指定设备或分组上执行。先在[技能库](./use-skills.md)中建立并实际验收技能，再启用定时运行。

在「定时任务」页面创建任务，填写名称、技能及版本、参数、设备或设备分组、Cron 表达式。调度统一使用技能状态机，不再选择经典或分层 workflow 模式。每台设备仍受队列与物理设备租约约束。

Cron 使用五个字段：分、时、日、月、周。例如 `0 8 * * *` 表示每天 8 点，`0 */2 * * *` 表示每两小时。保存后检查显示的下次执行时间，确认服务时区与预期一致。

编辑技能会创建新版本，不会改变已保存定时任务的版本。要采用新版本，需要编辑定时任务并重新选择。技能禁用、删除、版本或参数无效时，任务失败并记录原因，不自动选择其他技能。设备离线会记录失败，不执行替代设备。

卡片显示上次执行结果、成功设备数与总数；历史页提供逐步验收、路由和统计。只有后端服务运行时调度才会触发。

升级前的 workflow 定时任务显示为失效且禁用，须重新选择技能版本并填写参数。仅打开旧任务的启用开关不能恢复旧执行逻辑。原始配置会在首次改写前备份为 `scheduled_tasks.legacy.json`；系统不读取旧 `workflows.json`。
